# Commit Convention

Use Conventional Commits:

```text
<type>(optional-scope): <description>
```

Allowed types:

```text
feat
fix
refactor
perf
style
test
docs
build
ops
chore
```

Examples:

```text
feat(generator): detect chrome profiles across platforms
docs(workflow): add codex handoff diagram
test(generator): cover chrome-root profile selection
feat(extension): generate assignments template in chrome
```
